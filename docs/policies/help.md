# Getting help

Email **SI-HPC@si.edu**. Include:

- your Hydra username
- the job ID (`qstat` shows it; `qacct+ -j JOBID` for finished jobs)
- the full command or job script, and the error message verbatim
- what you expected to happen

For account and password requests see [Requesting an account](../getting-started/account.md).
