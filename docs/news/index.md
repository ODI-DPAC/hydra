# News

Change notices, upgrades, outages and new features, newest first. Major upgrades have their own pages under [Cluster upgrades](upgrades/index.md).

## 2025

**December 16.** The production RStudio server was upgraded with an updated OS and R version. See [RStudio](../hydra/interactive/rstudio.md).

**December 8.** QSubGen now includes virtual memory and GPU options. `qstat+` has new sorting and limiting options.

**December 5.** Scrubbing of files older than 180 days on the public disks resumes Sunday Dec 7; it had been suspended before the move to Ashburn. See [Scrubber](../hydra/storage/scrubber.md). Disaster-recovery backups of `/home` and `/data` to the cloud are paused pending an accounting issue; the NetApp filer holding them is unaffected and snapshots still work.
