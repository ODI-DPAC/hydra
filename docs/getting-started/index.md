If you have used a Slurm cluster elsewhere, note that Hydra runs the Altair (Univa) Grid Engine. The commands are `qsub`, `qstat`, `qdel` and `qrsh`, not `sbatch` and `squeue`. [How the scheduler works](../hydra/jobs/concepts.md) covers the differences.
