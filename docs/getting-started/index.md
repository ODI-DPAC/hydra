# Getting Started

If you are new to Hydra, work through these four pages in order.

1. [Request an account](account.md)
2. [Log in and set your password](login.md)
3. [Watch the required training video](training.md)
4. [Submit a first job](quick-start.md)

![Hydra's racks at the Ashburn data center](../assets/hydra-racks.jpg)

*Hydra's compute nodes at the Ashburn data center. (Image modified using AI to enhance color grading and reduce image noise.)*

If you have used a Slurm cluster elsewhere, expect different commands. Hydra runs Grid Engine, so you submit with `qsub` and check with `qstat` rather than `sbatch` and `squeue`. [How the scheduler works](../jobs/concepts.md) explains the differences.

When Hydra contributes to a publication, please [cite it](../policies/citing.md).
