# Getting started

A new user reads these pages in order:

1. [Request an account](account.md)
2. [Watch the introduction video](training.md), required for new users
3. [Log in and set your password](login.md)
4. [Submit a first job](quick-start.md)

[Cite Hydra](../policies/citing.md) in publications that used it.

If you have used a Slurm cluster elsewhere: Hydra runs Grid Engine. The commands are `qsub`, `qstat`, `qdel` and `qrsh`, not `sbatch` and `squeue`. [How the scheduler works](../jobs/concepts.md) covers the differences.
