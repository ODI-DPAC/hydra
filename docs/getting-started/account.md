# Requesting an account

Anyone affiliated with the Smithsonian, including SAO/CfA, requests a Hydra account the same way.

!!! note "A Hydra account is separate from your SI, CfA and VPN accounts"

    The username and password are set by the HPC team and are not synchronized with any other SI system.

## Request the account

Submit the [HPC Account Request](https://smithsonianprod.servicenowservices.com/si?id=sc_cat_item&sys_id=962e05331b96e05078932f41f54bcb3b&sysparm_category=8b5b9d421b601410520ba82eac4bcb65&catalog_id=9ff217131b531c1078932f41f54bcbf2) in the SI Service Portal (Accounts & Access catalog).

When the account is created you receive an email with your username and a link to set your initial password. The username is normally the same as your SI email name, in lower case.

## Request VPN access if you work off site

The login nodes accept connections only from the Smithsonian network, the SI VPN, or telework.si.edu. If you will work from outside SI, also submit a [VPN account request](https://smithsonianprod.servicenowservices.com/si?id=sc_cat_item&sys_id=cd8bcf38dbaec810faac7c031f961992&sysparm_category=8b5b9d421b601410520ba82eac4bcb65). Telework needs no extra account.

## Before you log in for the first time

New users are required to watch the [introduction to Hydra](training.md) video, which covers the [usage policies](../policies/usage.md) you agree to by using the cluster. Set your password from the link in the welcome email, then see [Logging in and passwords](login.md).
