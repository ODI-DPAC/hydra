# Interactive use

Do not run analyses on the login nodes. Processes that use too much CPU there are throttled and then killed. For interactive work use one of:

- [an interactive shell on a compute node](qrsh.md) with `qrsh`
- [Jupyter](jupyter.md)
- [VS Code](vscode.md) connected to a compute node
- [RStudio](rstudio.md), either on a compute node or the dedicated RStudio server
