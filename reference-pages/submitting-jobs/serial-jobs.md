A serial job is a job that uses only one CPU.


- It is either started by using a dedicated job script file (i.e. a different one for each job you need to run), or a more sophisticated job script that takes one or several arguments.
- Refer to the[Conceptual Examples](conceptual-examples.md)page to learn how to write jobs files and submit jobs.
- You can look under `~hpc/examples/serial` on Hydra for examples, using different compilers, of a trivial hello world program and job.
